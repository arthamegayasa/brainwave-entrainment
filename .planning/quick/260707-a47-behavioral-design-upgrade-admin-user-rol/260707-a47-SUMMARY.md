# Quick Task 260707-a47: Behavioral Design Upgrade + Admin/User Roles Summary

Goal-first preset renames, Supabase two-role schema with an admin publish/assign channel, and six behavioral-economics features (smart defaults, goal gradient, IKEA effect, reciprocity, loss aversion, contrast anchoring) — all client state in localStorage, zero new npm dependencies.

## What Was Built

### Task 1 — Data layer (commit 5740dba)
- **Migration 0002** (`supabase/migrations/0002_roles_library.sql`): `profiles` (role check user/admin, signup trigger + backfill), `is_admin()` (security definer, stable, pinned search_path — prevents RLS recursion and search-path hijack), `custom_audios` (spec jsonb), `audio_assignments` (composite PK). RLS on all three: profiles select-own-or-admin with NO client write policies; custom_audios admin-full + user select of templates/assigned; assignments admin-manage + select-own.
- **`src/lib/roles.ts`**: `fetchProfile()` with role coercion — unexpected values become "user".
- **`src/lib/audioLibrary.ts`**: full CRUD (`listAssignedAudios`, `listAllUsers`, `publishAudio`, `assignAudio`, `unassignAudio`, `listMyPublishedAudios`, `deleteAudio`); every cloud `spec` passes through `sanitizeSession` on read and failing rows are dropped (T-a47-01 mitigation).
- **`useEntitlement`** now returns `role`; `serenade.role.override` localStorage fallback documented and ignored when Supabase is configured (T-a47-04).
- **`PRICING.IDR.anchorAnnual`** (Rp588,000 = 12 × monthly) added without touching real amounts, ALL_UNLOCKED, or gating.
- 8 presets renamed goal-first (Sleeping, Meditating, Relaxing, Calming Anxiety, Focus & Concentration, Boosting Energy, Creative Flow, Power Nap); ids/Hz/carriers/premium flags unchanged. Landing copy aligned.

### Task 2 — Behavioral progress state, TDD (commits 3625560 RED, b6ec89d GREEN)
- `src/state/progress.ts` (pure TS, no React) under `serenade.progress.v1`: journey steps/percent (discovery auto-init — never 0%), 5-window `recommendedPresetId`, `setChosenGoals`/`skipGoalPicker`, `recordSessionCompleted` (400-entry cap), Mon-Sun `sessionsThisWeek`/`weeklyStreakDots`, `currentStreakDays` (yesterday-ending streak counts), reciprocity threshold at 2 sessions with persistent dismiss, corrupt-storage fallback.
- `tests/progress.test.ts`: 17 tests covering every behavior case including window boundaries (05:00, 10:59, 11:00, 21:00, 04:59).

### Task 3 — UI wiring (commit b7edc79)
- **`src/ui/builderEngine.ts`**: extracted Studio's engine singletons; Studio and Library share one AudioContext.
- **App**: `library` view; nav = Sessions/Library/Science/Premium with Studio inserted only for admins; studio view falls back to Library for non-admins; session completion recorded on natural end or manual stop at >= 5 minutes; SessionComplete view shown until dismissed.
- **Player**: new `SessionComplete` export — "Session #N this week", M T W T F S S streak dots, "Come back tomorrow to keep your streak."
- **Home**: Recommended-now one-tap hero (last-used prefs, preset default ambient), journey strip (bar + 4 steps, step 2 re-opens picker), first-visit multi-select goal picker (Continue/Skip), chosen-goals-first grid reorder, dismissible reciprocity card after 2 sessions linking to Upgrade. Playback never requires an account.
- **Builder**: admin-only Publish panel (goal tagline, publish-as-template, per-user assign from email dropdown, delete own published) rendered only when role === "admin" AND Supabase configured.
- **Upgrade**: struck-through Rp588,000 anchor beside Rp249,000 on annual (Save 58% pill and Rp20,750/mo line untouched), PREMIUM bullets rewritten to keep-framing, personal-stakes block (streak >= 2 shows streak line, else session count).
