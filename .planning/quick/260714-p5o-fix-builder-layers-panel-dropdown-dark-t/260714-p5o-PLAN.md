<audit_findings>
Pre-verified during planning — executor should trust these and NOT re-derive:

1. **Dropdown root cause:** `.select` (src/App.css lines 651-661) uses `background: rgba(255,255,255,0.05)` — an alpha color. Chromium derives the select popup background from the element's computed background-color; low-alpha composites to white while options inherit `color: var(--ink)` (light) → white popup, unreadable text. `color-scheme: dark` exists only on `:root` (src/index.css line 32); no `option`/`optgroup` styling exists anywhere.

2. **Flat list location:** `LAYER_TYPE_LABELS` + `LAYER_TYPES` in src/ui/Builder.tsx lines 38-49; the layer-type `<select>` maps `LAYER_TYPES` flat at lines 510-521. Engine semantics (src/audio/builder.ts): `ENTRAINMENT_TYPES = ["binaural","isochronic","monaural"]` (rampable, follow the session curve); `"pure"` maps to `createSolfeggioLayer` (static tone — NOT entrainment); `AMBIENT_TYPES = ["rain","ocean","wind","brown"]`.

3. **Ambience mapping audit result:** NO literal label swap exists. Verified consistent at every hop: Builder option value → `BuilderLayerSpec.type` → `builder.ts attach()` passes `spec.type` directly → `ambient.ts BUILDERS` map (rain→buildRain, ocean→buildOcean, wind→buildWind, brown→buildBrown) → engine.ts `LAYER_FACTORIES` (preset path) identical. The REAL root cause of "Rain sounds like Ocean": synthesis outputs are not perceptually distinct —
   - `ocean` = brown noise, lowpass 400 Hz, swell LFO at **0.1 Hz (10 s cycle)** — in a short audition the swell is inaudible, so ocean reads as static low rumble (≈ brown noise).
   - `wind` = white noise bandpass 600 Hz sweeping ±300 Hz at 0.15 Hz — slow low-mid whoosh that reads as ocean waves.
   - `rain` = static hiss (white noise, highpass 1000 / lowpass 7000) — correct character but nothing else in the set contrasts clearly.
   All parameters live in `DEMO.ambient` (src/audio/constants.ts lines 25-32) and are explicitly marked "ASSUMED — tune by ear".

4. **Test infra:** tests/audio/ambient.test.ts already renders each kind offline via `node-web-audio-api` and asserts rain ZCR > 3× ocean ZCR. helpers.ts exports `maxAbs`, `countZeroCrossings`. `npm test` = `vitest run`.

5. **Ambient layer fade-in:** `createAmbientLayer.start()` calls `fadeIn(output.gain, 1, t)` — envelope tests must skip the initial fade region (~first 2 s) before measuring modulation.
</audit_findings>
