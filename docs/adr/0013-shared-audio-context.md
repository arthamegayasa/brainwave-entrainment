# ADR-013: Satu AudioContext bersama dengan lifecycle perangkat (2026-09-25)

**Context:** Audio harus terdengar sama di perangkat berbeda. Audit menemukan: (1) dua `AudioContext` terpisah (preset + Studio) tanpa `latencyHint`; (2) iOS menaruh Web Audio di audio session `ambient` sehingga silent switch membisukan app; (3) interupsi OS (telepon, alarm, lock screen) membiarkan context `suspended`/`interrupted` tanpa umpan balik, dan `await ctx.resume()` yang tidak pernah selesai membuat tombol Start mati; (4) context idle terus me-render silence (baterai, memegang audio session); (5) noise ambience bergantung sample rate (level/warna berubah di 16k/96k/192k).
**Decision:** `src/ui/audioContext.ts` memiliki SATU context untuk SessionEngine dan BuilderEngine: `latencyHint: "playback"`, `navigator.audioSession.type = "playback"` (Safari 16.4+) sebelum dibuat dan di setiap play, `resume()` tanpa await (engine menjadwal di clock yang pause lalu berbunyi saat context jalan), auto-resume pada `statechange`/visibility/focus/gesture apa pun, banner "Resume audio" bila device menahan pause (atau start belum jalan setelah grace 1.5 s), dan suspend 1.5 s setelah tidak ada owner. Engine tetap context-agnostic. Noise disintesis per-Hz invariant terhadap sample rate (`NOISE_REFERENCE_RATE` 44.1 kHz). Engine membangun graph sebelum membaca `currentTime`.
**Consequences:** Start preset/custom kini sinkron (tidak ada lagi race "natural end mid-await"). Sesi yang di-interupsi pause di tempat karena mengikuti audio clock. Mode `playback` di iOS menghentikan musik app lain saat sesi dimulai (perilaku app musik/meditasi native). Carrier rendah di speaker kecil (174 Hz) tetap di luar kemampuan fisik speaker ponsel — keputusan produk terpisah.
**Status:** Accepted (implemented).
