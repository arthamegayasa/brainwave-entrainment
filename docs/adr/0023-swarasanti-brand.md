# ADR-023: Nama brand SwaraSanti; identifier teknis tetap `serenade` (2026-09-26)

**Context:** Nama Serenade dan domainnya (serenade.com dan sejenisnya) sudah dipakai pihak lain. Owner memilih SwaraSanti (*swara* = suara/nada, *santi* = damai); `swarasanti.com`, `.app` dan `.id` belum terdaftar per 2026-09-26. Beberapa identifier teknis memuat kata `serenade` dan tersimpan di perangkat user atau di Auth produksi.
**Decision:** Semua yang terlihat user memakai SwaraSanti: judul, manifest PWA, header, Media Session, nama file ekspor MP3 dan sesi (`.swarasanti.json`), halaman privasi (nama pengelola data), Science, label transaksi Midtrans, README dan dokumen. Identifier teknis yang tidak pernah tampil tetap: kunci localStorage `serenade.*.v1`, override `serenade.role.override`, dan domain email login internal `login.serenade.invalid` (ADR-018). Migration yang sudah diterapkan tidak diubah.
**Considered Options:** Mengganti semua identifier sekaligus (ditolak: kunci localStorage baru membuang sesi tersimpan, progres, preferensi, dan antrean Play yang belum terkirim di setiap perangkat; domain login internal baru memindahkan email Auth akun yang sudah ada, sementara `shownEmail` hanya mengenali satu domain).
**Consequences:** File `.serenade.json` lama tetap bisa diimpor karena impor menerima semua `.json`. Personal URL tetap mengikuti alamat tempat app dibuka (`window.location.origin`); saat domain SwaraSanti dipasang di Vercel, Site URL dan Redirect URL di Supabase Auth ikut diperbarui. `supabase/config.toml` `project_id` menjadi `swarasanti`, sehingga container lokal bernama `supabase_*_swarasanti` dan data stack lokal lama tidak terbawa.
**Status:** Accepted (keputusan owner, 2026-09-26).
