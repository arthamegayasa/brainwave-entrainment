# ADR-027: Alamat per halaman (2026-09-28)

**Context:** Semua view hidup di state `view` (`App.tsx`); hanya Personal URL (ADR-016) yang punya path. Reload selalu kembali ke Landing, halaman tidak bisa di-bookmark atau dibagikan, Back tidak berpindah antar halaman, dan halaman Science tidak bisa diindeks sendiri.
**Decision:** Setiap halaman punya alamat (`src/ui/pages.ts`): `/` Landing, `/sessions`, `/library`, `/dashboard`, `/studio`, `/science`, `/premium`, `/privacy`; `/p/<username>` tetap. Pindah halaman menambah entri history, Back dan Forward berpindah antar halaman, reload dan link membuka halaman yang sama, dan judul tab mengikuti halaman. Player dan sheet-nya tetap layer tanpa alamat: entrinya memakai alamat halaman di bawahnya, jadi Back menutup sheet lalu mengecilkan Player seperti sebelumnya. Alamat yang tidak menamai halaman (Personal URL yang ditinggalkan, path salah ketik, `/library/`) dan halaman Clinician yang dibuka akun tanpa kuasa Clinician (diganti Library setelah akun diketahui) diganti di tempat, sehingga Back dan reload tidak kembali ke sana. Vercel me-rewrite setiap path halaman ke `index.html`; path lain tetap 404.
**Considered Options:** React Router (ditolak: `backNavigation.ts` sudah memegang history untuk layer Player, dan dua pemilik history berebut `popstate` dan entri layer); Player dengan alamat `/player` (ditolak: tanpa Play yang berjalan halaman itu kosong, dan reload menghentikan audio); non-Clinician di `/studio` diarahkan ke Sessions (ditolak: app sudah menampilkan Library sebagai gantinya); rewrite catch-all di Vercel (ditolak: aset yang hilang ikut dijawab HTML 200, dan cache `scene-paintings` service worker bisa menyimpannya sebagai gambar).
**Consequences:** Halaman baru butuh entri di `PAGES` dan rewrite di `vercel.json`; `tests/pages.test.ts` menjaga keduanya karena `vite preview` menjawab path apa pun, sehingga E2E tidak melihat rewrite yang hilang. Tab nav yang menutup Player menunggu entri layer-nya keluar sebelum menambah alamat baru (`goToAddress`). ID view internal tidak berubah (`home` = Sessions, `upgrade` = Premium). Consequence ADR-016 "butuh router dan rewrite SPA di hosting" selesai dengan keputusan ini.
**Status:** Accepted (keputusan owner, 2026-09-28).
