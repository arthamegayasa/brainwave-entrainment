# README visuals

These files document Serenade without changing the app.

- `serenade-banner.svg`: original vector title artwork using the product's dark, mint, and lavender palette. The waves are decorative, not an EEG recording.
- `session-curve.svg`: original explanatory diagram derived from `src/audio/presets.ts` and `src/audio/schedule.ts`. It illustrates the 30-minute Meditating audio schedule: `(0, 10)`, `(12, 6)`, `(25, 6)`, `(30, 10)` in minutes and Hz. It is not a recording or a prediction of brain activity.
- `serenade-home.jpg`: actual local app landing screen.
- `serenade-sessions.jpg`: actual local app session-selection screen, captured around all eight preset cards.
- `serenade-session-setup.jpg`: actual local Meditating session setup dialog before playback.

Screenshots were captured on 2026-09-14 from the unmodified application with `npm run dev`, without a backend configuration or signed-in account. No patient information or fabricated application controls are shown. Images use relative paths so the README works in forks and offline checkouts.
