# README visuals

These files document SwaraSanti without changing the app.

- `swarasanti-banner.svg`: original vector title artwork using the product's dark, mint, and lavender palette. The waves are decorative, not an EEG recording.
- `session-curve.svg`: original explanatory diagram derived from `src/audio/presets.ts` and `src/audio/schedule.ts`. It illustrates the 30-minute Meditating audio schedule: `(0, 10)`, `(12, 6)`, `(25, 6)`, `(30, 10)` in minutes and Hz. It is not a recording or a prediction of brain activity.
- `swarasanti-home.jpg`: actual local app landing screen.
- `swarasanti-sessions.jpg`: actual local app session-selection screen, captured around all eight preset cards.
- `swarasanti-session-setup.jpg`: actual local Meditating session setup dialog before playback.

Screenshots were captured from the unmodified application with `npm run dev`, without a backend configuration or signed-in account: the landing and session-selection screens on 2026-09-26 (after the rename to SwaraSanti), the setup dialog on 2026-09-14. No patient information or fabricated application controls are shown. Images use relative paths so the README works in forks and offline checkouts.
